# 本棚スキャナ

本棚の写真から背表紙を読み取り、書誌情報を検索して蔵書一覧（CSV / JSON / Markdown / BibTeX / ISBN一覧）を作るツール。
サーバを持たない静的サイトとして GitHub Pages で動きます。

- 決定事項の要約（引き継ぎ用）: **[CLAUDE.md](CLAUDE.md)**
- 設計の背景: **[docs/CONCEPT.md](docs/CONCEPT.md)**

## 使い方

### 読み取り方式を選ぶ

| 方式 | 課金 | 範囲 | 手間 |
|---|---|---|---|
| **バーコード**（既定） | なし | 1冊ずつ | カメラをかざすだけ |
| **チャットAI** | なし | 棚ごと | 写真の添付と結果の貼り戻しが手動 |
| **背表紙の写真** | 従量 | 棚ごと | 全自動（APIキー必要） |

バーコードは設定不要で使えます。カメラは HTTPS でのみ動きます。

### そのあとの4段階

**ボタンで1段階ずつ進めます。**

1. **読み取る** — 上のいずれかの方式で本を取り込みます
2. **書誌データベースで照合する** — 実在確認が取れたものを確定します（ISBN が判っているものは日本の書籍に強い openBD を先に当てます）
3. **NDLサーチと突合する** — 国立国会図書館サーチと比較し、差分表示と欠損補完を行います
4. **openBD で情報を補う** — 出版社・発売日・書影などを補完します

段階を分けているのは、途中で止めて結果を確認できるようにするためと、
ある段階が失敗しても他の段階の成果を壊さないためです。

## 設定

### APIキー（背表紙の読み取りに必要）

静的サイトは秘密を持てないため、**利用者ご自身のAPIキーを使います**（BYOK）。
設定画面から Anthropic または Google Gemini のキーを登録してください。

- キーはブラウザの `localStorage` にのみ保存されます
- このアプリのサーバ（存在しません）には送信されません
- 読み取り実行時のみ、写真が選択したモデル提供元へ送信されます

### NDLサーチ用プロキシ（任意）

国立国会図書館サーチの API は CORS に対応しておらず、ブラウザから直接呼び出せません。
突合機能を使うには、ご自身で用意した CORS プロキシの URL を設定してください。

- 末尾が `=` の場合（例: `https://proxy.example/?url=`）— 対象URLをエンコードして連結します
- それ以外の場合（例: `https://proxy.example/`）— 対象URLをそのまま連結します

**未設定でも他の機能はすべて動作します。** NDL 突合は追加機能であって必須ではありません。

## データの保存先

蔵書データは IndexedDB に、設定は localStorage に保存されます。すべて利用者の端末内で完結します。

## 開発

```bash
npm install
npm run dev        # 開発サーバ
npm test           # 単体テスト
npm run build      # 本番ビルド
```

### デプロイ

`main` への push で GitHub Actions が自動デプロイします（`.github/workflows/deploy.yml`）。
リポジトリの Settings → Pages で Source を **GitHub Actions** に設定してください。

## 既知の制約

- **NDL のレスポンス解析は実地未検証** — 開発環境から NDL へ到達できなかったため、公開仕様に基づく実装です。名前空間接頭辞の揺れに耐えるよう防御的に書いてありますが、初回接続時に生のレスポンスを確認してください。
- **読み取り精度は写真次第** — 棚1段ずつ、正面から、明るい場所で撮ると精度が上がります。
- **モデルの捏造対策** — 読み取り結果は書誌DBで実在確認が取れたものだけを確定扱いにし、確認できないものは「未確認」として区別しています。
